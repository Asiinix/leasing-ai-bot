# Визуальный аудит main — BCC Leasing

Дата: 25 сентября 2026 года. Область: существующий интерфейс ветки `main`; версия Андрея не изменяется. Цвета BCC Leasing, логотип, двухколоночный макет и логика расчёта сохранены.

## Основание

В main используется локальный пакет `bcc-design` версии `1.6.0-leasing.1`. Проверены его исходники в `vendor/bcc-design/src`:

- `styles/themes/shared/spacing.scss`: базовый шаг 4 px, промежуточный 2 px; размеры контролов 24 / 36 / 48 / 56 px.
- `styles/themes/shared/typography.scss`: основной текст 16/24, компактный 14/20, подпись 12/16.
- `components/card/Card.scss`: карточка m — отступ 24 px, радиус 20 px; s — 16 px и 12 px.
- `components/form-control/base-form-control/BaseFormControl.scss`: стандартное поле высотой 48 px, внутренние отступы 12/16 px.
- `components/textarea/Textarea.scss`: типографика, скругление и состояния фокуса поля сообщения.

Экспорты установленной версии ограничены Button, Input, Textarea, Slider, Card, Typography, FormControl, Select и SegmentControl. Для отсутствующих компонентов приложения сохранён семантический HTML с токенами DS. API другой версии дизайн-системы не переносился.

- Чат: приветствие, раскрытие бюджета, перенос полей в одну колонку, интервал 12 px до textarea, отправка запроса, получение и применение предложения.
- Калькулятор: выбор процента аванса через BCC Select, отображение итогов и уведомления после применения условий.
- Выбор модели: пустая выдача, длинное название Bentley Continental Flying Spur на 320 px, Escape и закрытие диалога.
- График: 60 строк, диалог 288 px на экране 320 px, прокрутка таблицы внутри контейнера без расширения страницы.
- Фото и каталог относятся к отдельной локальной ветке фич и не включены в main.

Настоящая экранная клавиатура мобильного устройства и системный масштаб 200% не проверялись. Формула, данные API и ветка `andrey` не менялись.
