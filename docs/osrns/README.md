# ОСРНС

Отдельная плитка после калькулятора на порту 3000. Использует BCC Card, Select, Input и Tooltip. ОКЭД ищется по коду, русскому или казахскому названию; ГФОТ вводится в тенге за год. Подсказки объясняют оба термина. Заполненный расчёт автоматически добавляется в новое КП под КАСКО.

## Расчёт

`Стоимость за год = max(85 000 ₸, ГФОТ × тариф ОКЭД)`.

Минимум 85 000 ₸ — правило пользователя для демо. Тарифы используются как доли: значение Excel `0.0012` означает **0,12%**. В справочнике они хранятся целыми базисными пунктами, денежный расчёт округляется до тиына. Нулевой/пустой ГФОТ и неизвестный ОКЭД не создают предложение. До заполнения отображается только нижняя граница «от 85 000 ₸».

Примеры для ОКЭД 62011 (0,12%): ГФОТ 10 млн → расчёт 12 000, предложение **85 000 ₸**; ГФОТ 100 млн → **120 000 ₸**. ОКЭД 07101 (2,96%): ГФОТ 10 млн → **296 000 ₸**. Ведущие нули кодов сохраняются.

ОСРНС оплачивается отдельно: не прибавляется к ежемесячному лизинговому платежу, графику или КАСКО. В КП сохраняются только ОКЭД и ГФОТ, итог пересчитывается по встроенному справочнику. Старые ссылки КП без ОСРНС продолжают работать. Уже открытое КП не меняется при редактировании формы: для нового расчёта нажать «Показать КП» снова.

## Источник и импорт

- Файл пользователя: `Отбор клиентов МСБ для CRM_по ОКЭД.xlsx`.
- SHA-256: `d2f11894d3bb037830f470933985f8ff12fee8974e1bc48b488f677d7a5c49da`.
- Источник: лист `Класс риска`, диапазон `A4:E1110`; соответствия код/класс/тариф сверены с листом `ОТБОР NEW`.
- 1 105 строк тарифов, **1 104 уникальных ОКЭД**, 22 класса риска, ставки 0,12–2,96%.
- Код `28299` повторяется в строках 921 и 932 с одинаковыми классом и тарифом; объединён в одну запись. Во второй строке корректное казахское название, оно сохранено. Номера обеих исходных строк доступны в `sourceRows`.
- Лист `Research OSNS`, CRM-шаблоны и БИН не импортируются.

Повторный импорт из исходного файла:

```sh
python3 scripts/import-osrns-tariffs.py '/путь/Отбор клиентов МСБ для CRM_по ОКЭД.xlsx'
npx prettier --write src/features/osrns/tariffs.json
```

Импорт использует стандартную библиотеку Python, проверяет совпадение двух тарифных листов и не требует загрузки файла на внешние сервисы. Все тарифы встроены в приложение, внешний API не требуется.
