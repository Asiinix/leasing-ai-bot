# Проверка версии от 23.09.2026

## Автоматические проверки

- `npm run typecheck`: успешно.
- `npm run lint`: успешно.
- `npm test`: 40 тестов, 40 успешно.
- `npm run build`: успешная production-сборка Next.js 16.3.6.

Тесты проверяют формулу, график, округление, границы аванса/стоимости/бюджета, точные сочетания тарифов, русский разбор фраз, неоднозначные суммы, проверку API-параметров и возврат датированных резервных данных при сетевой ошибке.

## Живые API

Read-only проверка публичных справочных методов:

- Каталог — HTTP 200, source=live, 1 036 записей легковых автомобилей.
- ИП, Tucson 2875: 48 мес. / 20% → 24,15%; 60 мес. / 20% → 24,55%.
- Смена типа клиента на ТОО и записи модели на 2059 возвращает соответствующую отдельную матрицу.

## Проверено в браузере

1. Начальный пример 15 млн ₸ / 20% / 48 мес. → 392 218 ₸.
2. Запрос «До 350 тысяч в месяц, на аванс до 3 млн» → 60 мес., 349 057 ₸.
3. Применение меняет калькулятор; отмена возвращает исходный платеж.
4. График на 60 месяцев показывает суммы с двумя знаками и заканчивается нулевым остатком.
5. «Снизить первоначальный взнос» предлагает фактически меньший аванс: 15% / 2,25 млн ₸ на 60 месяцев при лимите исходного платежа.
6. Платеж до 250 тысяч при цене 15 млн и авансе до 3 млн → объяснение отсутствия подходящих условий и ориентир стоимости; предыдущие карточки отключены.
7. Пустая цена → вопрос о стоимости; короткий ответ «15 млн» продолжает подбор с сохраненным бюджетом.
8. «платеж350, аванс2млн» → уточнение единиц; «350 тысяч» сохраняет лимит аванса 2 млн.
9. Смена на Cobalt, ручная цена 6,49 млн → единственный срок 37 месяцев. При 25% аванса нарушен минимальный лимит стоимости, результат скрыт и показана причина.
10. Экран 390 × 844: горизонтального переполнения нет; поле ввода чата и кнопка применения доступны. Проверена также компоновка в две колонки при ширине 1440 px.
11. В просмотренных состояниях нет ошибок или предупреждений в консоли браузера.

## Ограничения проверки

Голосовой ввод реализован, но не тестировался записью с физического микрофона. Требует проверки в браузере и на устройстве ведущего. Банковская заявка не создавалась и не отправлялась. Переход открывает существующий сервис без автоматического переноса параметров.

Для сценического показа с неизменными цифрами рекомендуется сохраненный набор тарифов (`COLVIR_MODE=snapshot`), который явно помечается датой в интерфейсе.
