# Исследование API и проектная спецификация

Материалы подготовлены до реализации и описывают как проверенные методы, так и планируемый расширенный продукт. Фактический функционал текущего приложения и его ограничения описаны в корневом [README](../../README.md) и [продуктовом сценарии](../PRODUCT.md).

Текущий помощник использует локальный разбор типовых фраз без LLM, а предварительный график ведется с точностью до тиына. Исследование отдельно фиксирует исходные правила округления существующего сервиса BCC.
