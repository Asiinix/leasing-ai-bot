# Будущая функция: подбор автомобиля под платеж

Эти материалы сохранены для развития решения на хакатоне. **Прайс-каталог не подключен к текущему приложению.** В основной версии клиент вводит стоимость вручную, а справочник моделей используется только для выбора тарифов.

- [Исследование цен и сценарий](leasing-demo-price-catalog.md).
- [Пример каталога с комплектациями, источниками и датами](leasing-demo-car-catalog.json).
- [Снимок тарифов для исследовательских расчетов](leasing-demo-rate-snapshot.json).

Цены зафиксированы по публичным прайсам на 23.09.2026. Наличие, применимость скидок и окончательная цена покупки в лизинг не подтверждены. Для реализации потребуется обновляемый источник цен и отдельная проверка связи конкретных комплектаций с условиями финансирования.
