# BCC Design / BCC Leasing

Калькулятор и чат используют **реальные компоненты BCC Design 1.6.0** из предоставленного архива `arcade-frontend-master.zip`. Брендовая тема соответствует `bcc leasing brandbook 1.pdf` (Brand Guidelines 2024), разделам о логотипе, типографике и основной палитре.

## Источники и тема

- Библиотека: https://gitlab.bcc.kz/competence-center/arcade-frontend, `packages/bcc-design`.
- Оригинальный логотип: https://bccleasing.kz/themes/bcc/assets/images/samples/logo.png. Сохранён без изменения пропорций и цветов в `public/brand/bcc-leasing-logo.png`.
- Favicon: https://bccleasing.kz/themes/bcc/assets/favicon.ico.
- Blue `#2F6AC1`, Dark Blue `#183968`, Light Blue `#D5E6FF`, Black `#000000`, White `#FFFFFF` — брендбук, страница PDF 18 (печатный номер 16).
- Inter, основной текст Medium, заголовки Bold; Arial — запасной шрифт. Файлы Inter поставляются локально через `@fontsource-variable/inter`, без запросов к Google Fonts. Пакет включает кириллицу и расширенную кириллицу.

`DesignProvider` подключает upstream `ThemeProvider` в режиме `bcc-light`. Класс темы присутствует в серверном HTML до гидратации. `body.leasing-theme` переопределяет брендовые CSS-переменные, поэтому hover, focus, selected и disabled используют ту же тему. Нейтральные поверхности, ошибки, размеры и скругления — из BCC Design. Основной макет калькулятора и чата сохранён.

## Компоненты

| Интерфейс                                | Компонент BCC Design                                 |
| ---------------------------------------- | ---------------------------------------------------- |
| Действия и подсказки чата                | `Button`, через тонкий адаптер `ui.tsx`              |
| Тип клиента и срок лизинга               | `SegmentControl`                                     |
| Цена, бюджет, сумма аванса, поиск модели | `Input`                                              |
| Ползунок стоимости, включая клавиатуру   | `Slider` / `rc-slider`                               |
| Карточки параметров и расчёта            | `Card`                                               |
| Заголовок страницы и основных блоков     | `Typography.Title`                                   |
| Ввод сообщения                           | `Textarea`                                           |
| Выбор процента аванса                    | `Select` с библиотечными `Dropdown` и `SelectOption` |

Нативный `dialog` оставлен для фокус-ловушки, Escape, блокировки прокрутки и восстановления фокуса; внутри используются BCC-кнопки и поля. Нативная таблица сохраняет заголовки и отдельную прокрутку графика. У Select и SegmentControl исправлена доступность архивной реализации; системных выпадающих меню браузера в форме больше нет.

## Локальный пакет

Зависимость: `bcc-design: file:vendor/bcc-design`. В проект включены только используемые runtime-модули и их зависимости, SCSS и собранные ESM/CSS/декларации. Nx, Storybook, снимки, внутренние конфиги и SuisseIntl не переносятся. Корневой `package.json` исходного архива указывает MIT; исходное авторство BCC сохраняется.

Архив и отдельные upstream-файлы идентифицируются SHA-256 в `vendor/bcc-design/upstream-manifest.json`. Алиасы монорепозитория преобразованы в относительные импорты. `src/index.ts` содержит только нужные экспорты.

```bash
npm ci
npm run build:design-system
npm run typecheck
npm run lint
npm test
npm run build
```

Команды `dev` и `build` автоматически пересобирают локальную библиотеку. Собранный `dist` хранится вместе с исходниками: редактор и TypeScript могут разрешать типы сразу после установки. CI и Railway не требуют корпоративного npm registry, VPN или GitLab-токенов. Изменения upstream нужно вносить в `vendor/bcc-design/src`, затем выполнять `npm run build:design-system`; вручную редактировать `dist` не следует.

Декларации старого пакета выпускаются без диагностики (`noCheck`, аналогично upstream `skipDiagnostics`). Код приложения проверяется строгим TypeScript; vendored upstream исключён из линтера приложения.

## Минимальные исправления upstream

1. `BaseButton`: `href` передаётся в ссылку (в upstream он терялся); disabled/loading исключают переход. Сохраняется явно переданный `aria-pressed`; обычные кнопки не объявляются переключателями. `tabIndex` сохраняется, disabled/loading исключены из порядка фокуса.
2. `BaseInput`: контролируемое поле использует React `onChange` вместо `onInput`; внешний `aria-label` сохраняется. Это устраняет предупреждение React 19 и сохраняет доступные имена полей поиска и суммы аванса.
3. Тип `ElementState` импортируется через публичный экспорт `@maskito/core` вместо приватного пути.
4. Lodash закреплён на 4.18.1: у старой версии из периода upstream есть опубликованные уязвимости. Нужен библиотечному ползунку для debounce.
5. `Select`: добавлены роли combobox/listbox, связи ARIA и активная опция, стрелки, Home/End, Enter/Space, Escape и закрытие по Tab/blur. Поле без поиска доступно только для чтения; клик повторно открывает меню, выбор текущего значения не сбрасывает аванс. Опции сохраняют фокус в поле, поддерживают click/touch и disabled. Обводка активной опции появляется при навигации клавиатурой.
6. `Dropdown`: портал создаётся после mount для SSR/гидратации Next.js; список учитывает границы окна, при необходимости открывается вверх и пересчитывает позицию при прокрутке/resize. Закрытый список скрыт от accessibility tree.
7. `SegmentControl`: нативные кнопки с radio-семантикой, одна остановка Tab, стрелки и Home/End, disabled. Библиотечная подложка позиционируется по индексу выбранного элемента, включая внешнее изменение срока из чата; пропорциональная ширина сохраняется при resize.

Интеграционные CSS-правила ограничивают стили кнопок элементами `button`/`a`, учитывают вложенный BEM span библиотеки и сохраняют контурные иконки Lucide.

Фокус поля рисует его скруглённая поверхность BCC: внутренний input/textarea не добавляет вторую прямоугольную рамку. Цена и Slider объединены одной поверхностью `MoneyInput`, с отдельным клавиатурным фокусом бегунка. Ошибка сохраняет красную границу при фокусе и наведении. У кнопок одна внешняя обводка без изменения размера. Поля `MoneyInput` имеют связанные HTML-label; пустая подпись boolean-ошибки BCC скрыта, текст валидации остаётся в форме.

## Проверка миграции

- 40 тестов финансового расчёта, интерпретации сообщений и API проходят.
- Браузер: редактирование цены, ползунок с клавиатуры, смена аванса, поиск модели и очистка цены при смене автомобиля.
- Чат: отправка по Enter и через форму бюджета, предложение 349 057 ₸ при цели 350 000 ₸ и авансе 3 млн, применение и отмена.
- График: 48 строк, нулевой последний остаток, Escape и восстановление фокуса.
- Desktop и mobile: перенос колонок, доступные действия чата, отсутствие горизонтального переполнения.
- Повторная проверка состояний: пустая/ошибочная цена, поиск, сообщение и бюджет, readonly/disabled, Select мышью и клавиатурой, фокус кнопок и сегментов; ширины 1440, 390 и 320 px.

Расчёт, эндпоинты, правила помощника, браузерный speech-to-text и условия перехода к заявке не менялись. Работа реального микрофона этой миграцией не проверяется.
