# Цены учебного каталога

Фиксация: **25 сентября 2026 года**. Данные предназначены для локальной демонстрации на хакатоне.

В таблице `src/features/fixed-price-catalog/price-snapshot.json` сохранены цены **всех 1 036 записей модель + партнёр** исходного каталога Colvir. В ней 6 датированных цен из публичных прайсов (`reference`) и 1 030 синтетических учебных бюджетов (`estimate`). Синтетические суммы не являются текущими рыночными ценами, оценкой автомобиля, подтверждением наличия или предложением дилера.

## Как показывать цену

- `reference`: **«Цена по прайсу»**. Показывать исходную ссылку и `priceCheckedAt`. Шесть ранее подготовленных фикстур, их комплектации, годы и цены сохранены без изменения.
- `estimate`: **«Ориентировочная демо-цена»**. Показывать `priceBasis`; дата фиксации — `priceEstimatedAt`. `priceSourceUrl`, `priceCheckedAt`, `trim` и `modelYear` равны `null`: для этих записей конкретное предложение не проверялось.

Фотография марки не подтверждает модель, поколение, комплектацию или цену выбранного автомобиля. Тип фотографии хранится отдельно от типа цены.

## Методика синтетических сумм

`price-rules.ts` содержит явно заданные семейства моделей 72 марок. Числа — авторские сценарные бюджеты в миллионах тенге, округлённые до 100 000 ₸. Никаких случайных чисел, изменения по дате запуска или наценки из ID партнёра нет.

У марки нет единой цены для всех моделей: например, Toyota Passo / Camry / Land Cruiser 300 относятся к разным бюджетам; Hyundai Getz / Tucson / Palisade, BMW X1 / X5 / X7 и Kia Picanto / Sportage / EV9 также различаются. Ранние семейства, компактные автомобили, седаны, кроссоверы, коммерческий транспорт и премиальные автомобили имеют разные сценарные суммы. Это поддерживает разнообразие демо, но не заменяет оценку по году выпуска, пробегу, состоянию, поколению, комплектации и документам продавца.

После подгонки под границы программы **844 оценки** остаются семейными (`model-family`), **185** скорректированы до допустимой границы (`lease-bounds`), **1** (`VOLKSWAGEN Tcg`) использует бюджет сегмента (`segment-estimate`). Нечёткие названия исходного справочника и ID сохраняются.

## Границы демо-цен

По просьбе пользователя цены всего демо-каталога приведены к диапазону **6 250 000–62 500 000 ₸** — сохранённым ограничениям при авансе 20%. Например, Matiz теперь имеет демо-цену 6 250 000 ₸. Исходная оценка хранится в `originalPriceKzt`. Шесть прайсов уже входят в диапазон и сохранены.

После получения собственных тарифов модели `fitVehicleToTerms` дополнительно приводит цену к ближайшему допустимому интервалу. Это нужно для других авансов, типа клиента и изменившихся лимитов. Одинаковая функция работает в калькуляторе и подборе карточек. Пробелы между интервалами не считаются допустимыми. После выбора другого аванса автоматическая демо-цена также учитывает его диапазон. Ручной ввод не корректируется автоматически.

Скорректированная цена всегда становится `estimate` / `lease-bounds`; ссылка и дата дилерского прайса убираются, исходная сумма сохраняется. Это распространяется и на опубликованную цену, если новые ограничения потребовали её изменить. Отсутствие собственных ставок не исправляется ценой: тарифы не создаются и не переносятся с другой модели.

## Новые модели API

Статическая цена присоединяется только при совпадении `modelId`, `partnerId`, нормализованных марки и модели. Переиспользованный ID с новым названием не наследует старый прайс. Новая модель получает детерминированный бюджет своего семейства, а при отсутствии совпадения — сегмента марки. Для неизвестной марки задан нейтральный учебный бюджет 12 млн ₸; явные слова компактного/коммерческого сегмента корректируют его. Происхождение всегда `estimate`, никогда `reference`.

Сохранённые шесть прайсов нельзя переносить между партнёрами или на другую комплектацию. Цена другой записи может быть близкой, но остаётся синтетической оценкой без ссылки на дилерский источник.

## Откуда взялись шесть прайсов

Исходные значения и отдельные ссылки находятся в `docs/roadmap/leasing-demo-car-catalog.json`: Chevrolet Cobalt, Hyundai Elantra/Tucson/Sonata, Kia Seltos/Sportage. Дата их проверки — 23.09.2026. У Tucson год обычной цены не подтверждён и остаётся `null`.

Для проверки масштаба учебных сегментов просмотрены официальные страницы [Chevrolet](https://chevrolet-auto.kz/models/cobalt), [Hyundai](https://hyundai.kz/ru/find-a-car/cars/elantra-2023/price-configuration/), [Kia](https://kia.com.kz/models/new_sportage/) и [Chery](https://chery.kz/ru/cars/). Эти страницы **не являются источниками 1 030 индивидуальных оценок**: оценки не выдаются за опубликованные на них предложения. В частности, акционные значения со страниц не переносятся на неизвестные комплектации.

## Перегенерация

Из корня проекта:

```sh
node --import tsx docs/pricing/regenerate.mjs
```

Команда использует только локальный `colvir-snapshot.json`, шесть сохранённых прайсов и версионированные правила. Сеть, текущий рынок и системная дата не используются. После изменения правил поднять `PRICE_RULES_VERSION`, осознанно обновить `PRICE_ESTIMATED_AT`, перегенерировать таблицу и запустить:

```sh
node --import tsx --test tests/vehicle-pricing.test.ts
```

Наличие цены не означает наличие разрешённого тарифа: подбор ежемесячного платежа по-прежнему требует собственных ставок и ограничений именно этой модели.
