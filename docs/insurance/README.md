# Страховка для демо

По запросу пользователя ставки — **годовой процент от полной стоимости автомобиля**:

| Категория             | Ставка в год | Записей в каталоге |
| --------------------- | ------------ | ------------------ |
| Легковые машины       | 2,2%         | 909                |
| Грузовые              | 0,65%        | 110                |
| Прицепы и спецтехника | 0,44%        | 4                  |
| Автобусы              | 1,3%         | 13                 |

Всего 1 036 записей модели/продавца. Годовая сумма равна полной цене авто × ставке. По просьбе пользователя интерфейс показывает только стоимость за год, без эквивалента в месяц. Это отдельный расчёт, он не добавляется в основной лизинговый платёж, график или сумму финансирования. Цена автоматически меняется вместе с автомобилем и учитывает существующую подгонку демо-цен под границы лизинга. Аванс и срок не меняют ставку страховки. Тумблер по умолчанию выключен.

Классификация — упрощённая для хакатона, как согласовано пользователем. В `categories.ts` описаны исключения для грузовиков, пикапов, автобусов, фургонов и специального транспорта. Кроссоверы, внедорожники и пассажирские минивэны входят в легковые. Предварительные назначения смешанных модельных семейств отмечены в данных `needsReview`; интерфейс не требует их подтверждать и позволяет при необходимости сменить категорию. Переход к другому автомобилю автоматически берёт его категорию, не переносит ручной выбор предыдущей модели. Тумблер остаётся в выбранном положении.

Полная таблица: [catalog-classification.json](catalog-classification.json). Категории и годовые ставки также находятся в объектах каталога приложения. Поиск в каталоге дополнен фильтром по категориям. Для регенерации таблицы:

```sh
node --import tsx docs/insurance/regenerate.mjs
```

Правила для неоднозначных семейств опираются на названия из исходного каталога и страницы производителей: [Hyundai H350 — фургон, автобус и шасси](https://trucknbus.hyundai.com/global/products/van/h350), [JAC N35 — грузовик](https://www.jactrucks.kz/models/jac-n35/), [Chevrolet Labo — мини-грузовик](https://chevrolet-auto.kz/models/labo), [ГАЗ Next — A31R33 фургон и A65R33 автобус](https://gazauto.kz/upload/userfiles/files/%D0%93%D0%90%D0%97%20%D0%9D%D0%B5%D0%BA%D1%81%D1%82%2015-04-2026.pdf), [УАЗ 2206 и 3962](https://www.uaz.ru/blog/news/uaz-teper-sootvetstvuet-standartu-evro-4). Эти источники не задают страховые ставки: ставки предоставлены пользователем. Уточнение типов по VIN для демо не требуется.

Название в интерфейсе — **«Страхование КАСКО»**, сумма — «КАСКО за год». Рядом с названием размещён `Tooltip` из BCC Design: работает при наведении, фокусе с клавиатуры и нажатии; закрывается по Escape или нажатию вне подсказки. Текст описывает страхование автомобиля от повреждений и угона, конкретное покрытие зависит от полиса. Основа пояснения: [АРРФР](https://www.gov.kz/memleket/entities/ardfm/press/news/details/1058454?lang=ru).

Тумблер — оригинальный `Switch` из предоставленного архива BCC Design, вместе с `ToggleControl`. Сохранённые исходные хеши добавлены в `vendor/bcc-design/upstream-manifest.json`; импорты переписаны на относительные, как у остальных компонентов локальной сборки. Страница использует стандартные токены BCC и бренд BCC Leasing.

В `Select` добавлена привязка портала к ближайшему нативному `dialog`, если селект находится внутри него. Это позволяет выбирать категорию в фильтре каталога: портал в `body` был бы за пределами активного модального слоя. Обычные селекты формы продолжают использовать `body`; позиционирование учитывает реальный offsetParent.

Tooltip перенесён из того же архива BCC Design с относительными импортами. Локальные адаптации: уникальный id, доступный триггер Button, поддержка касания без двойного переключения, Escape, закрытие при скролле/ресайзе, ограничение ширины на мобильных и очистка таймера закрытия.
