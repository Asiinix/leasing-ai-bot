# BCC Leasing · калькулятор и помощник

Рабочий фронт для демонстрации на саммите: React 19, Next.js 16 App Router и TypeScript. Дизайн повторяет согласованные экраны: калькулятор слева, расчет или чат справа, белые и серые поверхности, зеленые действия.

**[Открыть опубликованное демо](https://leasing-ai-bot-production.up.railway.app/)** · [Управление проектом Railway](https://railway.com/project/86dfc36d-19a3-47fd-9e0b-96b0d64478fc)

## Запуск

В проекте зафиксирован Node.js 24.

```bash
npm ci
npm run dev
```

Открыть [http://127.0.0.1:3000](http://127.0.0.1:3000).

Для показа готовой сборки:

```bash
npm run build
npm start
```

По умолчанию используются доступные публичные справочники BCC. Для репетиции без внешней сети:

```bash
COLVIR_MODE=snapshot npm start
```

Перезапускайте сервер при смене режима. `.env.example` можно скопировать в `.env.local` и выбрать `live` или `snapshot`.

Для Railway: сборка через Railpack командой `npm run build`, запуск `npm start`, проверка готовности по `/`. Сервер слушает `0.0.0.0` и порт из переменной `PORT`, которую задает Railway. После подключения репозитория к сервису нужно выпустить публичный домен в Networking. Дополнительная база данных не требуется.

Опубликованный сервис использует окружение `production`, ветку `main` и домен с целевым портом `8080`. Режим данных — `live`, с автоматическим возвратом к датированному резервному набору при недоступности BCC.

На момент публикации 23.09.2026 Railway показывает `Auto deploy unavailable`: автодеплой новых коммитов пока не подключен. Для обновлений используйте `Deploy Latest Commit` в палитре команд Railway. Для включения автодеплоя потребуется предоставить Railway GitHub App доступ к этому репозиторию и обновить подключение — [инструкция Railway](https://docs.railway.com/deployments/github-autodeploys).

## Что работает

- Выбор ИП/ТОО, модели и продавца из справочника без цен. Обычный автолизинг; для ТОО — срок деятельности более года. Лизинг Стартап не реализован.
- Ручная стоимость из предложения продавца. Начальные 15 млн ₸ явно обозначены как пример, это не рыночная цена Tucson. При смене модели стоимость очищается.
- Мгновенный расчет аванса, финансирования и ежемесячного платежа по конкретной тарифной строке.
- Помощник понимает типовые русские запросы о цене, платеже, авансе и сроке, в том числе числительные и уточнения. Показывает до трех вариантов и объясняет отсутствие подходящих условий.
- Применение выбранного предложения, сравнение с исходным расчетом, отмена. Старые предложения отключаются после изменения параметров или бюджета.
- График с точностью до 0,01 ₸, корректирующий последний платеж и выгрузка CSV.
- Адаптивный интерфейс, клавиатурная навигация, диалоги с удержанием фокуса, обработка загрузки, ошибок и отсутствия тарифов.
- Голосовой ввод через SpeechRecognition браузера. Запись включается только пользователем. Распознанный текст можно проверить до отправки. В неподдерживаемом браузере появляется объяснение; текстовый ввод доступен всегда.

## Сценарий показа за минуту

1. Нажать «Пример расчета»: ИП, Hyundai Tucson, общий каталог, условная цена 15 млн ₸, аванс 20%, срок 48 месяцев.
2. Показать предварительный платеж около 392 218 ₸ при сохраненных тарифах от 23.09.2026.
3. Открыть «Подобрать с ИИ» и отправить: «Хочу платить до 350 тысяч в месяц, на аванс до 3 млн».
4. Помощник предложит 60 месяцев и около 349 057 ₸. Нажать «Применить условия».
5. Показать изменение калькулятора, график и «Отменить».
6. Для демонстрации ограничений задать «До 250 тысяч в месяц, аванс до 3 млн»: вместо выдуманного предложения появится объяснение и ориентир допустимой стоимости.

Живые ставки могут измениться; для воспроизводимого сценического примера используется `COLVIR_MODE=snapshot` с видимой датой тарифов.

## ИИ-помощник и заявка

Помощник консультирует по автолизингу, рассчитывает условия и заполняет заявку через диалог. Чат, калькулятор и форма заявки работают с одним черновиком (`src/lib/draft.ts`): у каждого поля есть источник (пример, форма, чат) и ревизия. Черновик и история чата хранятся в `localStorage` браузера и переживают перезагрузку.

- `POST /api/assistant` — модель OpenAI (`OPENAI_MODEL`, по умолчанию `gpt-5.4-mini`) с серверными инструментами: прочитать черновик, обновить поля, найти автомобиль, получить условия, рассчитать, подобрать варианты, проверить готовность, показать итог, передать менеджеру. Каждый аргумент проверяется на сервере; расчеты — только `src/lib/finance.ts` по тарифам BCC. Текст модели данные не меняет: изменения приходят отдельным патчем и применяются, только если пользователь не изменил поле после отправки сообщения.
- Подтвержденные факты для консультации — `src/lib/knowledge.ts`. Все, чего там нет (документы, выкуп, комиссии, сроки рассмотрения), помощник называет отсутствующим и направляет к менеджеру.
- Без ключа или при недоступности модели работает упрощенный детерминированный режим на тех же инструментах, с пометкой в чате.
- `POST /api/transcribe` — голосовые сообщения: запись в браузере, распознавание `OPENAI_TRANSCRIBE_MODEL`; текст можно поправить перед отправкой. Аудио не сохраняется.
- `POST /api/applications` — отправка заявки только кнопкой после проверки итога и согласия. Сервер заново проверяет данные и пересчитывает платеж. Повтор с тем же ключом или тем же содержимым в той же сессии возвращает ту же заявку. Заявки сохраняются в JSON-файл (`APPLICATIONS_FILE`) с хешем сессии.

**Не подключено:** передача заявки в систему BCC (подтвержденного API нет — после сохранения клиент продолжает в сервисе BCC Leasing) и передача обращения менеджеру. Хранилище заявок — JSON-файл с персональными данными (ФИО, телефон, e-mail, ИИН); на Railway без тома он не переживает перезапуск.

## Границы этой версии

Голосовое распознавание зависит от браузера и его сервиса распознавания; поддержка русского голоса с реальным микрофоном требует проверки на устройстве ведущего. Аудио не отправляется нашим приложением на собственный сервер. Обработка звука определяется браузером.

В расчете только основной долг и проценты. Комиссии, страхование, особенности НДС и выкупной платеж не включены. Предварительный график этого демо ведется в тиынах; он не заменяет договорный график BCC. Неокругленный аннуитет используется для проверки бюджета, округление до целых — только для крупных чисел в интерфейсе.

Перед заявкой клиент проходит симуляцию скоринга, затем форму заявки: параметры лизинга и контакты — ФИО, электронная почта, телефон и ИИН (12 цифр) — и согласие на обработку персональных данных. Ошибки показываются под полями после потери фокуса или попытки отправить; фокус переходит на первое ошибочное поле. Заявка отправляется только кнопкой и сохраняется в этом сервисе с номером обращения; в систему BCC автоматически не передается — это объясняется клиенту, дальше оформление продолжается в сервисе BCC Leasing. Контакты в браузере не сохраняются (только в памяти страницы) и уходят на сервер лишь вместе с заявкой. ИИ-модели имя и телефон передаются замаскированными, e-mail и ИИН — никогда; в логи сервера персональные данные не пишутся.

**Прайс-каталог автомобилей намеренно не включен.** Его можно реализовать на хакатоне как развитие: цены конкретных комплектаций с источниками и датами, наличие у партнеров и предложения моделей под бюджет. Подробности — в [docs/PRODUCT.md](docs/PRODUCT.md).

## Структура

- `src/app` — страница, метаданные, стили и два разрешенных API-маршрута.
- `src/components` — калькулятор, помощник, выбор модели, диалоги, график.
- `src/lib/colvir.ts` — серверный адаптер: проверка схем, нормализация, таймауты, ограниченный кэш и резервные данные.
- `src/lib/finance.ts` — чистые функции расчета, графика и подбора.
- `src/lib/assistant.ts` — интерпретация русских фраз; финансовых вычислений здесь нет.
- `src/data/colvir-snapshot.json` — сохраненные справочники и тарифы от 23.09.2026 без прайс-каталога и контактных данных.
- `tests` — проверки расчета, ограничений, интерпретации запросов и поведения API.

Маршруты: `GET /api/catalog`, `GET /api/terms?modelId=2875&clientType=IP`.

К внешнему API обращается сервер Next.js, поэтому браузеру не требуется обход CORS. Все внешние адреса фиксированы в адаптере; пользователь не может подставить свой URL. Внешние операции создания заявки, OTP или подписания отсутствуют. Входные параметры проверяются до обращения к сервису.

Тарифы кэшируются на минуту, справочники — на 10 минут. При ошибке используется согласованный сохраненный набор с `source: snapshot` и датой исходных данных. Резервные ставки есть для семи исследованных записей моделей; для остальных офлайн показывает отсутствие условий, ничего не подставляя.

### Коммерческое предложение

После расчёта кнопка «Сформировать коммерческое предложение» открывает просмотр с
необязательным именем клиента / компании. «Скачать PDF» создаёт A4-документ с
логотипом, параметрами, итогами и полным графиком. Имя файла и дата используют
часовой пояс Asia/Almaty. Суммы в сводке округляются так же, как в калькуляторе;
итоги и график сохраняют два знака после запятой.

PDF генерируется локально в браузере (jsPDF + AutoTable). Имя клиента не отправляется
на сервер и не сохраняется. Шрифт Noto Sans загружается с того же сайта, лицензия
SIL OFL находится в `public/fonts/OFL.txt`. Изменение расчёта закрывает старый просмотр
и отменяет его незавершённое скачивание. Контакты не добавляются: в проекте они не настроены.

Проверка сценария: `npm run build && npm run test:e2e`. Перед первым запуском:
`npx playwright install chromium`; для проверки извлечённого PDF-текста нужны
`pdftotext` и `pdfinfo` из Poppler (`brew install poppler` на macOS).
Тесты используют фиксированные ответы справочников и проверяют совпадение данных,
кириллицу, все строки графика, A4, имя файла, ошибку/повтор и отмену старой генерации.
PDF и снимок просмотра сохраняются в игнорируемой Git папке `test-results/`.
